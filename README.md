Hospital Patient Management System is a desktop application built in Python with a Tkinter GUI and SQLite database for persistent storage of patient records. 
It allows users to add, view, search, update, and delete patient information using SQL CRUD operations, ensuring efficient data management. 
The system uses linked list concepts for internal logic (if implemented) and database connectivity for permanent data storage and retrieval. 
This project demonstrates practical use of GUI design, database integration, and core data handling operations.
